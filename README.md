# Bomberman

A Bomberman-style game built with Bevy.

## Setup

1. Install Rust (latest stable)
2. Build and run:

```sh
cd bevy-release-0.17.3
cargo run --example breakout
```

For faster builds:

```sh
cp .cargo/config_fast_builds.toml .cargo/config.toml
```

## Project Structure

- `bevy-release-0.17.3/` - Game engine and source code
- `bevy-release-0.17.3/examples/` - Example games and demos
